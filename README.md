# Digital Media Agency Platform

A full-featured marketing and client management website built with Next.js and Tailwind CSS.

## Features
- Client management dashboard
- Social media profile tracking
- Brand and digital media management
- GA4, GSC, and Clarity-ready analytics sections
- Responsive landing page
- Vercel deployment ready

## Tech Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- Recharts
- Lucide Icons

## Run locally

```bash
npm install
npm run dev
```

Then open: http://localhost:3000

## Deploy to Vercel
1. Push this repository to GitHub.
2. Import it into Vercel.
3. Add env values from `.env.example`.
4. Deploy.

## Replace placeholders
Add your actual social media handle URLs in `.env.local` before deployment.
